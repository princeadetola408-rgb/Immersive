Laptop Computer

1.1 DEFINITION OF COMPUTER

A computer is an electronic device that accepts raw data as input, processes it according to instructions, and produces meaningful information as output.

1.2 CHARACTERISTICS

  • Speed: Can perform millions of calculations per second
  • Accuracy: Gives correct results if input is correct - GIGO
  • Storage: Can store large amount of data
  • Versatility: Can do many different types of work
  • Diligence: Never gets tired

    • KEY POINT

    The 5 components: Hardware, Software, Peopleware, Data, Procedure. Remember: HSPDP
    Topic 2: Types of Computers
    Micro Computer
    Mainframe Computer
    Super Computer

    2.1 BY SIZE & CAPACITY

  • Micro: For personal use. E.g PC, Laptop, Smartphone
  • Mini: For small company/department
  • Mainframe: For big company/bank. Handles many users
  • Super: For weather, space, science. Very fast
    • Topic 3: Hardware and Software
    Hardware
    Software

    3.1 HARDWARE

    Physical parts you can touch. E.g Monitor, Keyboard, CPU, Mouse, Printer

    3.2 SOFTWARE

    Programs and Instructions.
  • System Software: Windows, Linux, Android
  • Application Software: MS Word, Chrome, Games
    • Topic 4: Input and Output Devices

    4.1 INPUT DEVICES

    Used to enter data into computer. E.g Keyboard, Mouse, Scanner, Microphone, Webcam

    4.2 OUTPUT DEVICES

    Used to show result. E.g Monitor, Printer, Speaker, Projector
    Topic 5: Computer Memory

    5.1 TYPES OF MEMORY

  • RAM: Random Access Memory. Volatile. Temporary
  • ROM: Read Only Memory. Permanent. Has boot instructions
  • Cache: Very fast memory between CPU and RAM
  • Secondary: HDD, SSD, Pen Drive for long storage
    • Topic 6: Operating System

    6.1 DEFINITION

    Software that manages computer hardware and provides interface between user and hardware.

    6.2 EXAMPLES

    Windows, Linux, MacOS, Android, iOS

    6.3 FUNCTIONS

    File management, Memory management, Security
    Topic 7: Computer Programming

    7.1 DEFINITION

    Process of writing instructions for computer to follow to solve a problem.

    7.2 PROGRAMMING LANGUAGES

    Python, C++, Java, HTML, JavaScript

    7.3 STEPS

    Problem Analysis → Algorithm → Coding → Testing → Debugging
    Topic 8: Data Representation

    8.1 NUMBER SYSTEMS

  • Binary: Base 2. Uses 0,1
  • Decimal: Base 10. Uses 0-9
  • Hexadecimal: Base 16. Uses 0-F

    • 8.2 DATA TYPES

    Text, Number, Image, Audio, Video
    Topic 9: Internet and Web

    9.1 INTERNET

    Network of networks. Connects computers worldwide.

    9.2 WWW

    World Wide Web. Uses HTTP, URL, Browser to access websites.

    9.3 SERVICES

    Email, Chat, Social Media, Cloud Storage
    Topic 10: Computer Ethics and Safety

    10.1 COMPUTER ETHICS

  • Don't hack or spread virus
  • Don't plagiarize. Respect copyright
  • Don't use computer to commit fraud
